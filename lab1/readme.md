#### 形状对比总结表

| 操作             | 形状     | 视觉表示           | 典型用途        |
| ---------------- | -------- | ------------------ | --------------- |
| `x`              | `[3]`    | `[10, 20, 30]`     | 一维张量        |
| `x.unsqueeze(0)` | `[1, 3]` | `[[10, 20, 30]]`   | 增加 batch 维度 |
| `x.unsqueeze(1)` | `[3, 1]` | `[[10],[20],[30]]` | 增加列维度      |

------

#### 为什么在你的代码中要加 `unsqueeze(0)`

LSTM 要求输入格式是 `[batch_size, seq_len]`（因为你设置了 `batch_first=True`），
 如果你只输入一个序列 `[seq_len]`，那就少了 batch 维。
 所以你要：

```python
input_idx = input_idx.unsqueeze(0)
```

变成 `[1, seq_len]`，告诉模型：

> “我现在给你 1 个样本（batch=1），这个样本的序列长度是 seq_len。”

#### 假设我们一开始有一个一维张量

```python
x = torch.tensor([10, 20, 30])
print(x.shape)  # torch.Size([3])
```

可以把它想成这样一个“行向量”：

```
[10, 20, 30]
```

形状是：

```
Shape: [3]
```

#### 一、执行 `x.unsqueeze(0)`

```python
x = x.unsqueeze(0)
print(x.shape)  # torch.Size([1, 3])
```

📊 现在形状变成 `[1, 3]`，相当于加了一行的维度：

```
[[10, 20, 30]]
 ↑
 batch_size = 1
```

形象地说：

- 之前是 “一个长度为3的向量”
- 现在是 “1个样本，每个样本有3个数”

✅ 常用于给 RNN / LSTM 添加 **batch 维度**

------

#### 二、执行 `x.unsqueeze(1)`

```python
x = torch.tensor([10, 20, 30])
x = x.unsqueeze(1)
print(x.shape)  # torch.Size([3, 1])
```

📊 现在形状变成 `[3, 1]`：

```
[
 [10],
 [20],
 [30]
]
```

形象地说：

- 这是 3 行 1 列的“列向量”
- 每一行代表一个元素

✅ 常用于给线性层或卷积输入添加 **通道或列维度**
